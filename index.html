Nalox Aura fixes that with Nalox Connect: the panel asks, you click one Connect button in Chrome, and your sign-in is handed to the panel on your own computer. Quick Tutorial

The five things every editor asks first — each takes under a minute.

Watch: The Full Setup in About a Minute

No voice, just watch and follow — install, connect Chrome, open the panel. The same video is inside the panel too: Settings → Tutorial.

Install Nalox Aura

  1. Unzip the downloaded file.
  2. Double-click INSTALL.bat and wait for the success message.
  3. Run SETUP.bat once — it installs the helper tools and checks your connection.
  4. Restart After Effects, then open Window → Extensions → Nalox Aura.
  5. Complete the one-time welcome screen (Subscribe + Follow) to unlock the panel.

Install a Font

  1. Open the Fonts tab and type the font name in search.
  2. Pick Google Fonts or DaFont as the source.
  3. Press Install on the card — the font is added to your PC automatically.
  4. Use it in any text layer right away.

Apply a Preset

  1. Select the layer in your composition first.
  2. Open the Presets tab and pick a category.
  3. Click a preset card — it applies instantly.
  4. Presets marked Deep Glow need the Deep Glow plug-in on your PC.

Unlock Nalox AI PRO

  1. Open the Nalox AI tab — it shows your PC's Machine Code.
  2. Send that code to us in an Instagram DM.
  3. You receive your personal 6-digit PRO code — one code works on one PC only.
  4. Type the code in the panel — Nalox AI unlocks: chat, agent mode and project building.

Update to the Latest Version

  1. When an update is ready, the panel header shows an Update pill.
  2. Open Settings → Updates and press Download and Install.
  3. Close and reopen the panel — you are on the new version.

Make Captions in Seconds

  1. Open the Captions tab and import your SRT file — or paste lines, one per caption.
  2. Choose a style: Clean, Bold Pop, Boxed, Minimal or Karaoke.
  3. Set the size and highlight colour, then press Build — captions appear as timed text layers.
